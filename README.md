# PhonePe Transaction Analysis Dashboard

## Project Overview

This project is an interactive Power BI dashboard developed to analyze PhonePe transaction data across multiple financial services. The dashboard provides insights into transaction volume, payment success rates, failure reasons, and service-wise performance.

The report consists of 5 interconnected pages with interactive navigation, filters, and visualizations to help users monitor and analyze transaction activities effectively.

---

## Objectives

- Analyze transaction performance across PhonePe services.
- Track successful and failed transactions.
- Identify major payment failure reasons.
- Compare transaction trends across different services.
- Provide business insights through interactive visualizations.

---

## Dashboard Pages

### 1. Home Dashboard

The Home page provides an overall summary of PhonePe transactions.

Features:
- Total Transaction Amount
- Total Transactions
- Successful Transactions
- Failed Transactions
- Service-wise Amount Analysis
- Monthly Transaction Trend Analysis
- Payment Failure Reason Distribution

---

### 2. Insurance Dashboard

Provides detailed insights into insurance-related transactions.

Features:
- Insurance Transaction Count
- Insurance Type Analysis
- Payment Status Distribution
- Failure Reason Analysis
- Insurance Category Comparison

Insurance Categories:
- Term Life
- Car Insurance
- Bike Insurance
- Health Insurance

---

### 3. Loans Dashboard

Provides loan transaction analysis.

Features:
- Loan Transaction Count
- Loan Category Performance
- Payment Status Monitoring
- Loan Failure Analysis

Loan Categories:
- Auto Loans
- Mutual Funds
- Gold Loans
- Credit Score Services

---

### 4. Money Transfer Dashboard

Provides analysis of money transfer transactions.

Features:
- Transfer Volume Monitoring
- Transaction Success Rate
- Failure Reason Analysis
- Service-wise Performance


Money Transfer Categories:
- To Self Account
- To Mobile Number
- To UPI I'd 
- To QR Code
---

### 5. Bills & Recharge Dashboard

Provides bill payment and recharge transaction insights.

Features:
- Recharge Analysis
- Utility Bill Transactions
- Payment Success Monitoring
- Failure Trend Analysis

Bills & Recharge Categories:
- Electricity Bill's
- DTH
- Cable TV
- Mobile Recharge

- Identified major causes of transaction failures.
